# Capstone 1 - Hospital Employee Data

Project ini merupakan aplikasi sederhana berbasis Python untuk mengelola data karyawan di lingkungan rumah sakit.  

---

## Tentang Project

Aplikasi ini berjalan melalui menu interaktif di terminal, yang memungkinkan pengguna untuk melakukan beberapa proses pengelolaan data karyawan, seperti:

- Melihat seluruh data karyawan
- Menambahkan data karyawan baru
- Menghapus data karyawan
- Mengubah data karyawan yang sudah ada
- Exit dari program

---

## Fitur yang Tersedia

### 1. Menampilkan Data Karyawan  
Menampilkan semua data karyawan dalam bentuk tabel agar lebih mudah dibaca.

### 2. Menambah Data Karyawan  
Pengguna dapat menambahkan data karyawan baru dengan mengisi beberapa informasi seperti ID, nama, jabatan, divisi, tahun masuk, status, dan tanggal lahir.

### 3. Menghapus Data Karyawan  
Data karyawan dapat dihapus berdasarkan nomor urut yang dipilih pengguna.

### 4. Mengubah Data Karyawan  
Memungkinkan pengguna untuk mengedit data karyawan yang sudah ada.

### 5. Keluar Program  
Mengakhiri aplikasi.

---

## Konsep yang Digunakan

Dalam project ini digunakan beberapa konsep dasar Python, seperti:

- Dictionary dan list sebagai struktur data
- Perulangan (loop)
- Percabangan (if, elif, else)
- Input dan output user
- Function untuk memecah program agar lebih rapi
- Indexing data

---

## Tujuan Project

Project ini dibuat untuk melatih pemahaman dasar Python, terutama dalam:
- Pengelolaan data sederhana
- Logika CRUD (Create, Read, Update, Delete)
